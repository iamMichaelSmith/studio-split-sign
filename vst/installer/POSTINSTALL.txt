Split Sheet Studio was installed in two places:

1. Standalone app
   - Program Files\Blak Marigold Studio\Split Sheet Studio

2. VST3 plugin
   - Program Files\Common Files\VST3\Split Sheet Studio.vst3

To use it in a compatible Windows DAW:

1. Close the DAW before installing or updating the plugin
2. Open the DAW's plug-in manager or plug-in settings
3. Make sure the standard Windows VST3 system folder is enabled
4. Rescan new, failed, or blocked plug-ins if needed
5. Search for "Split Sheet Studio" under VST3 effects
6. Load it on a compatible audio or instrument track

Important:
- The standalone app does not need to remain open while using the VST3
- Default hosted API target is https://app.splitsheetstudio.com
- Sign in with a valid Split Sheet account from inside the plugin
- Product website: https://splitsheetstudio.com
